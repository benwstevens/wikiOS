# This folder is wikiOS's upstream repo

If the user wants to install wikiOS in their own workspace, or says "set up wikiOS," "set me up," or "install this": read `SETUP.md` in full and follow it. It explains the system, gives you the interview to run with the user, and says what to build.

If the user is maintaining wikiOS itself (porting a rule up from an install, adopting one down): read `system/githubsync.md`. Rules only; no wiki content is ever committed here.
