# LLM rules — origins

Each entry matches one line in `.system/LLM-rules.md`. Add a new entry when the owner corrects something or a lesson lands; date it and name the incident. If the rule should govern every session, propose the one-line version for `LLM-rules.md` and ask before adding it. Never let a rule exist only in the model's private memory: the value of the system is seeing where any hardened rule came from.

Entry shape: **Rule, as a short bold lead** (owner, date; recurred date if it did). What happened, in two or three sentences, with the owner's words where they were captured. *How to apply:* one or two sentences. Optional: a self-test.
